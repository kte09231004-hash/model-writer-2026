| 변수 유형 | 자동 판단(ID·이분형·범주형·연속형) 후 '변수 유형 확인'(접힘)에서 수정. ID는 역할 목록에서 제외, ID 중복 시 반복측정·군집 자료 가능성 경고 |
| 지원하지 않는 자료 차단 | 이분형·범주형 종속변인(매개변인 포함), 3개 이상 범주의 X·W·공변인, 이분형으로 지정했지만 값이 2종이 아닌 변수, 상수 변수, 완전한 선형 종속(회귀식과 변수 이름을 밝혀 안내) |
| 기초통계 | 결측 현황 표(변인별 결측 수·비율, 제외 사례), 연속형 기술통계(n·M·SD·최솟값·최댓값), 범주형 빈도, Pearson 상관표(연속형끼리). 모두 모형과 같은 분석 표본 |
| 척도 신뢰도 | 문항 점수 계산 기능을 재사용해 척도별 문항 수·산출 방식·역채점·결측 기준·n·Cronbach α 보고. 문항 자료가 없으면 '산출 불가' |
| 회귀 진단(접힌 '분석 진단') | 회귀식별 VIF·공차, Cook의 거리, 레버리지, 표준화 잔차, 잔차-예측값 그림, 잔차 Q-Q 그림. 중요한 신호(조절 구성항 제외 VIF ≥ 10, Cook's D > 1)만 접힌 영역 밖에 짧게 표시. 자동 삭제·자동 판정 없음 |
| HC3 강건 표준오차(선택) | 회귀계수 SE·t·p·CI, 회귀식 F(Wald), 상호작용 검정, 조건부 효과, Johnson-Neyman, 표 주석·문장·설정 기록에 일관 반영. 간접효과 부트스트랩 구간은 SE 방식과 무관 |
| 보고서 구성 | ① 통계 분석 방법 ② 분석 대상과 결측치 처리 ③ 기술통계·상관 ④ 척도 신뢰도 ⑤ 매개/조절 결과 ⑥ 회귀 진단과 주의사항. 자료로 알 수 없는 내용은 '[작성 필요: …]' |
| 직접 고친 문장 보호 | 문단을 고친 뒤 결과가 다시 생성되면 알림을 띄우고 이전 수정본을 보관·복사할 수 있게 함 |
| 보고 형식(기본: 학술지 논문 형식) | 참고 논문 2편(발달지원연구 15(2) 순차매개 논문, 인문사회21 14(2) 순차매개 논문)의 표·문장 구성을 따름. 표 1 = 상관 + M·SD·최솟값·최댓값·왜도·첨도, 회귀 표 = 종속변인·예측변인·β·B·SE·t(유의 표시)·R²·CI LL·UL(상수 행·p 열 없음), 효과 표 = 총효과·직접효과·(총)간접효과·간접효과1~, 본문은 (B, p)와 (B, 95% CI)만 쓰고 표·그림 번호를 참조, 1 미만 값은 앞자리 0 생략, 그림은 표준화 계수(β)와 비유의 경로 점선. '상세 형식'으로 바꾸면 본문에 SE·t, 표에 p 열과 상수 행이 나옴(재분석 불필요) |
| 참고 논문과 다르게 둔 것 | 분석 도구는 실제 사용한 이 도구로 표기(SPSS·PROCESS로 쓰지 않음), 직접효과 유의성만으로 완전·부분매개를 판정하지 않음, 왜도·첨도 값은 제시하되 정규성 판단과 근거 문헌은 '[작성 필요]', 문장은 구성만 따르고 그대로 옮기지 않음 |
| 연구 정보 입력(선택, 접힘) | 연구 대상·자료 수집, 연구설계, 연구가설, 공변인 선정 근거, 범주형 변수의 코드 의미(예: 0 = 남성, 1 = 여성). 입력하면 문장·표에 반영, 비우면 '[작성 필요]'. 계산에는 영향 없음 |
| 기술통계 보강 | 왜도·첨도(표본 보정 통계량, SPSS·pandas와 같은 정의) |
| 통계 기호·약어 주석 | 표마다 B·β·SE·t·R²·CI·LL·UL 등과 유의 표시(*, **, ***) 설명 |
| 데이터 지문 | 분석에 쓴 자료의 행 수·변수 수·내용 해시를 설정 기록·보고서·JSON에 남김(같은 이름의 다른 파일 구분) |
| 변수 정리(2단계) | 변수마다 한 줄에 논문에 쓸 이름·유형을 입력. 범주형은 값마다 뜻을 적는 칸이 자동으로 생김(예: 1 = 남성). '연구대상 특성' 체크로 인구통계 표 포함 여부 지정. 이름이 이어지는 문항(dif1~dif7)은 자동으로 묶어 한 줄로 보여 주고 '척도 만들기'로 문항·응답 범위를 미리 채움(응답 범위는 관찰값이므로 확인 안내를 함께 표시). 만든 척도는 삭제 가능 |
| 연구대상 특성(인구통계) | 모형에 넣지 않은 변수도 분석 표본 기준으로 범주형은 빈도·비율, 연속형은 평균·표준편차·범위를 표와 문장으로 제시. 3개 이상 범주(학력 등)도 가능(회귀식 투입은 여전히 미지원) |
| 하위요인 신뢰도 | 만든 척도는 모형에 쓰지 않아도 신뢰도 표와 문장에 '(하위요인·기타)'로 포함 |
| 통합 보고서 | 분석을 하나씩 실행해 '담기'를 누르면 여러 분석을 한 문서로 저장. 자료분석·연구대상·기술통계·신뢰도는 한 번만 쓰고 표·그림 번호를 이어서 매김. 자료·결측치 코드·변수 유형이 바뀌면 담아 둔 분석을 표시하고 저장을 막으며, '모두 다시 실행'으로 갱신 |
| 단계 순서와 변수 역할 칸(0.5.1) | (단계 순서는 0.7.0에서 바뀜, 아래 '화면 구성' 줄 참고) 0.5.1의 순서: 데이터 → 분석 모형 → 변수 정리 → 변수 역할 → 연구 정보 → 옵션·실행. 역할 칸은 모형 그림과 같은 순서로 세로 배치(단순매개 X → M → Y, 순차매개 X → M1 → M2 → M3(선택) → Y, 조절 X·W·Y)하고 제목 옆에 필요한 변인 수를 안내. 역할로 고른 변인은 공변인 후보에서 빠짐 |
| 엑셀 이름·코드북 반영(0.5.2) | 열 이름이 한글이면 '논문에 쓸 이름' 칸에 그대로 채움(고칠 수 있음). 엑셀 파일에 코드북 시트가 있으면 값의 뜻을 자동으로 채우고(값의 뜻이 3개 이상이면 범주형으로 판단), 문항 묶음에 코드북의 응답 범위·역문항 수를 표시하며, '척도 만들기'에 그 값을 채움. '코드북대로 모두 만들기'로 척도 전체 점수와 하위요인을 한꺼번에 생성(문항 평균). 자료는 코드북이 아닌 첫 시트에서 읽고, 어떤 시트를 읽었는지 안내 |
| 추가 검정(0.6.0, 0.7.0부터 기본으로 켜짐) | 분석 옵션의 체크로 표·문장을 넣고 뺌(다시 분석할 필요 없음). ① 다중공선성 확인: 회귀식별 공차·VIF 표와 확인 문장(검토 기준 VIF 10 또는 5 선택). 예측변인이 하나인 회귀식은 판단 대상에서 제외, 조절모형을 원점수 곱으로 만든 경우 X·W·상호작용항은 구조적 공선성이라 판단에서 제외 ② 간접효과 경로 간 차이 검증(순차매개만): 간접효과 두 개씩 차이를 같은 부트스트랩 표본에서 구해 SE·백분위수 신뢰구간 산출(효과 차이 또는 절댓값 차이 선택). 부호가 다른 두 효과는 크기 비교로 해석하지 않으며, 다중비교 보정은 하지 않음 |
| 화면 구성(0.7.0) | 왼쪽 단계 순서: ① 데이터 불러오기 → ② 변수 정리(척도 만들기 포함) → ③ 분석 모형과 변인 지정(모형을 고르면 바로 아래에 그 모형의 변인 칸) → ④ 분석 옵션 → ⑤ 연구 정보(선택). '분석 실행' 단추는 왼쪽 아래에 고정되어 스크롤 없이 누를 수 있고, 그 위에 지금 지정된 모형·변인(또는 남은 할 일)을 한 줄로 보여 줌 |
| 처음 화면(0.7.0) | 예시 결과를 자동으로 띄우지 않고 사용 안내만 보여 줌. '예시 데이터로 결과 먼저 보기'를 누르면 예시 결과가 나오며 결과 위에 '예시 데이터의 결과'라고 표시. 새 파일을 불러오면 이전 자료의 결과·담아 둔 분석을 비움(다른 자료의 결과가 흐리게 남지 않음). 직접 올린 자료가 있을 때 예시 단추는 한 번 더 눌러야 바뀜 |
| 척도 만들기(0.7.0) | 문항 묶음의 '척도 만들기'를 누르면 그 묶음 바로 아래에 입력 칸이 열림(이름 확인 → 역문항 번호 선택 → 만들기). 만들면 다음 묶음의 입력 칸이 이어서 열려 위아래로 오갈 필요가 없음. 코드북이 있으면 응답 범위·역문항이 채워져 있고 '코드북대로 모두 만들기'로 한 번에 만들 수도 있음. 하위요인 점수는 목록에서 접어 두고, 변인 선택 목록은 척도 점수·하위요인 점수·그 밖의 변수로 나눠 보여 줌. 여러 묶음을 합치거나 일부 문항만 쓰는 경우는 아래 '문항을 직접 골라 척도 점수 만들기' 사용 |
| 값의 뜻 안내(0.7.0) | '연구대상 특성'에 체크한 범주형 변수의 값의 뜻이 비어 있으면 입력 칸을 강조하고, 결과 위에 해당 변수와 해결 방법(뜻을 적거나 체크를 빼기)을 알림. 비워 두면 문장·표에 '코드 1'처럼 나옴 |
| 결과 바로가기(0.7.0) | 결과 위쪽에 고정된 줄에서 분석 방법·결과 서술·표 1~n·그림·진단·저장으로 바로 이동. '입력 칸 접기'로 결과만 넓게 볼 수 있음 |
| 글자 크기·화면 밝기(0.7.0) | 머리말의 단추로 글자 크기(보통·크게·더 크게)와 밝은/어두운 화면을 바꿈. 이 브라우저에만 기억함 |
| 경계선 결과 알림(0.7.0) | 간접효과나 간접효과 차이의 부트스트랩 신뢰구간 한계값이 0에 매우 가까우면(백분위수 한계값의 몬테카를로 표준오차 3배 이내, 정규 근사) 결과 문장과 차이 검증 표 주석에 '난수 시드나 반복 횟수에 따라 유의 판정이 달라질 수 있음'을 적음. 판정 자체는 바꾸지 않음 |
| 분석 상태 표시 | 분석 전 / 분석 중 / 현재 입력으로 성공 / 입력 변경으로 재분석 필요 / 실패. 재분석 필요·실패 상태에서는 이전 결과를 흐리게 표시하고 복사·저장·문단 편집을 막음 |

계산 방식: 최소제곱(OLS) 회귀, 일반 표준오차(기본) 또는 HC3, 사례 재표집 부트스트랩, 백분위수 신뢰구간.
브라우저 안에서 계산함. 서버로 데이터를 보내지 않음.

### 코드북 시트 형식
엑셀 파일 안에 아래 열 이름을 가진 시트를 두면 코드북으로 읽음(시트 이름은 상관없음). '변수명' 열과, 나머지 열 중 하나 이상이 있어야 함.

| 열 이름 | 내용 | 예 |
|---|---|---|
| 변수명 | 자료 시트의 열 이름과 똑같이 | 성별, 완벽주의적자기제시_01 |
| 값 라벨 | 범주형 변수의 값과 뜻 | 1 = 남자, 2 = 여자 / 1 = 1학년 … 4 = 4학년 |
| 척도 | 문항이 속한 척도 이름(같은 척도의 문항은 같은 이름) | 한국판 완벽주의적 자기제시 척도(PSPS-K) |

| 역문항 | 역문항이면 '역문항'이라고 적음 | 역문항 |

### 비교 기준 (제안)
| 항목 | 기대 | 판단 기준 |
|---|---|---|
| 분석 사례 수 | 같음 | 완전 일치 |
| 회귀계수·SE·t·p·R²·F | 같음 | PROCESS 출력 자릿수(소수 4자리)에서 일치 |
| 간접효과 점추정 | 같음 | 소수 4자리 일치 |
| 조건부 효과 | 같음 | W 값이 같다면 소수 4자리 일치 |
| 조절변인 백분위 값 | 확인 필요 | 백분위 계산 정의가 다르면 W 값이 달라질 수 있음 → 차이 나면 정의를 맞춤 |
| 부트스트랩 신뢰구간 | 근사 | 난수 생성기가 달라 정확히 같을 수 없음. 우리 도구를 시드만 바꿔 여러 번 돌린 결과 범위 안에 PROCESS 값이 들어오는지 확인 |

## 5. 아직 하지 않은 것

- SPSS PROCESS 비교
- 실제 연구 자료(또는 공개 예제 자료)로 시험
- 사용자(팀원·초보 연구자) 사용성 점검
- (완료) 웹 배포: GitHub Pages `https://kte09231004-hash.github.io/model-writer-2026/`
- 워드(.docx) 직접 저장(현재는 HTML 보고서·표 복사로 대체)
- (0.6.0에서 추가) 간접효과 경로 간 차이 검증, 다중공선성 확인 옵션. 계산은 독립 검산과 일치하나, 간접효과 차이를 SPSS PROCESS의 contrast 출력과 비교하는 작업은 아직 하지 않음
- 추가 검정의 문장·표 구성(다중공선성 확인 문장, 경로 간 차이 문장)은 시연 파일과 예시 데이터에서 화면으로 확인함. 문장 표현을 모든 경우에 대해 따로 점검하는 스크립트는 없음
- 경계선 결과 알림의 기준(몬테카를로 표준오차 3배)은 정규 근사에 따른 내부 기준이며 문헌의 판정 규칙이 아님
- Johnson-Neyman '계산 불가' 상태: 코드에는 있으나, 이 상태를 일으키는 실제 데이터로는 시험하지 못함
- 한글(HWPX) 내보내기: 후순위로 미룸. 현재는 HTML 보고서·표 복사
- 다범주 독립·조절변수(더미 코딩), 로지스틱 회귀, 반복측정·다층 자료, CFA·SEM, 다중대치: 미지원(해당 자료는 분석 전 차단 또는 경고)
- 반복측정·군집 자료는 ID 중복으로만 확인함. 데이터만으로 확실히 판별할 수는 없음
- 척도 출처, 왜도·첨도 판단 기준과 근거 문헌, 진단 결과에 대한 판단은 입력받지 않고 '[작성 필요]'로 남김
- 성별·연령에 따른 t 검정·분산분석, 다범주 변수의 회귀식 투입(더미 코딩)은 지원하지 않음
- 불성실 응답 제외 같은 사례 선별 기능은 없음(업로드 전에 정리하고 '연구 정보'에 직접 기재)
- 통합 보고서의 문단은 자동 생성 문장임(분석별 화면에서 손으로 고친 문장은 통합 보고서에 반영되지 않음)
- 통합 보고서의 연구대상·기술통계·신뢰도는 담아 둔 모든 분석 변인에 결측이 없는 사례 기준임. 분석별 사례 수가 다르면 그 사실을 문단에 적음
- 조절모형은 참고 논문에 예시가 없어 같은 원칙(예측변인·B·SE·t·R²·CI)으로 구성함
- HC3를 SPSS PROCESS(hc3 옵션)와 비교하는 작업은 아직 하지 않음
- 이전 결과를 따로 저장하는 기능은 두지 않음(재분석 필요·실패 상태에서는 저장 차단)
