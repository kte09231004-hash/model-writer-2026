계산 방식: 최소제곱(OLS) 회귀, 일반 또는 HC3 표준오차, 사례 재표집 부트스트랩, 백분위수 신뢰구간.
브라우저 안에서 계산함. 서버로 데이터를 보내지 않음.

### 상태 관리 규칙
- 재분석이 필요한 입력: 데이터 교체, 결측치 코드, 문항 점수 변수 생성, 모형, X·Y·M·W·공변인, 중심화, 조건부 효과 지점, 신뢰수준, 부트스트랩 횟수·시드(매개모형)
- 출력만 바꾸는 설정(변인 이름, 소수점, 도구 이름): 다시 계산하지 않고 화면·복사·CSV·그림·보고서·JSON에 즉시 반영함. 이때 손으로 고친 문단은 새로 생성된 문단으로 바뀜
- 마지막 성공 분석은 결과·설정·분석 사례 수·사용한 파일 이름·결측치 코드·문항 점수 설정을 한 묶음으로 보관함. 새 분석이 성공할 때만 통째로 교체함
- 입력을 마지막 성공 분석과 같게 되돌리면 정상 상태로 돌아옴

## 3. 검증 결과 (완료된 것)

### 0.6.0 (2026-11-19)

- **추가 검정을 끈 상태의 출력이 이전 버전과 같음:** 단순매개·순차매개(매개 2·3개, HC3 포함)·조절모형에서 이전 엔진·보고 모듈과 표·결과 문장·분석 방법 문단이 글자 단위로 같음을 확인
- **statsmodels 대조:** 예시 데이터로 회귀계수·SE(일반 OLS·HC3)의 차이 1e-13 이하, VIF 상대오차 1e-15 이하
- **간접효과 경로 간 차이:** 점추정 = 두 간접효과의 차이임을 확인. 두 방향(i − j, j − i)은 부트스트랩 값에서 각각 직접 계산함
- **논문 재현용 가상 데이터(N = 250) 대조:** 김수진·이소연(2026) 순차매개 연구의 공개 요약 통계로 만든 가상 자료로 분석함
  - 부트스트랩과 무관한 값(평균, SD, 상관, 경로계수, R², 간접효과 점추정, Y 회귀식의 VIF·공차)은 논문 보고 자릿수에서 일치함
  - 같은 척도 점수로 Python statsmodels를 따로 돌린 결과와도 소수 넷째 자리까지 일치함
  - 간접효과 차이 C1(Ind1 − Ind2)은 신뢰구간 하한이 0 근처인 경계 사례임(20만 회 부트스트랩 기준 하한 −.0011). 5,000회로 시드 1~100을 돌리면 31번 유의, 69번 비유의로 나와 시드에 따라 결론이 바뀜

※ 아래 기록은 0.6.0 이전 버전에서 한 검증이며, 0.6.0에서 같은 스크립트를 다시 돌리지는 않았음.

### 이전 버전

**독립 검산: Python statsmodels와 비교 → 504개 항목 모두 일치(상대오차 1e-8 이하)**

- 대상: 단순매개(공변인 2개), 순차매개(매개 2개·3개), 조절(원점수·평균중심화·이분 조절변인)
- 회귀계수, SE, t, p, 신뢰구간, R², F, MSE
- 표준화 계수(β): z점수 회귀로 별도 계산해 비교
- 간접효과 점추정, 총효과 = 직접효과 + 총간접효과
- 부트스트랩: 같은 재표집 순서를 Python에서 재현해 신뢰구간·Boot SE 일치 확인
- 조건부 효과: W를 이동시킨 별도 회귀로 비교
- Johnson-Neyman 경계값에서 |t| = 임계값 확인

**Johnson-Neyman 독립 검증: 126개 항목 모두 일치** (`verify/verify_jn.py`)

- 기준 구현: statsmodels 0.15.0 OLS로 W를 w만큼 이동해 다시 추정한 X 계수의 t(= w에서의 조건부 효과 t)를 W 관측 범위 3,001개 격자에서 계산하고, |t| − t임계값의 부호가 바뀌는 지점을 scipy 1.18.1 brentq(xtol 1e-12)로 찾음
- 허용오차: 경계값 상대오차 1e-6, t임계값 1e-8, 범위 밖 경계값은 그 지점의 |t|가 임계값과 1e-6 안에서 같은지 확인
- 사례: 예시 데이터(`sample_scores.csv`)의 90·95·99% × 원점수·평균중심화, 공변인 포함, 합성 데이터 4종(범위 전체 유의·전체 비유의·범위 안 전환·경계값이 범위 밖)
- 평균중심화 전후의 경계값과 구간 판정이 같은 원점수 W에서 일치함을 확인

**화면 점검: 44개 항목 통과** (`verify/ui_test.js`, Chromium + Playwright)

- X=Y 실패, 모형·옵션만 변경, 되돌림 복구, 재실행 복구, 데이터 교체, 결측치 코드, 공변인, 문항 점수, 시드·부트스트랩 횟수
- 출력 설정 즉시 반영과 클립보드·HTML 보고서·CSV·SVG·PNG·JSON 일치, 같은 시드 재실행 결과 동일

※ 이것은 '우리 코드가 의도한 계산을 정확히 수행한다'는 검증임.

## 4. SPSS PROCESS 비교 검증 (아직 하지 않음)

### 준비물
- SPSS + PROCESS 매크로 (버전 기록 필수: 예 v4.2)
- `sample/sample_scores.csv`

### PROCESS 실행 설정 (신택스 예시)
```
process y=distress /x=alex /m=avoid /cov=age gender /model=4 /total=1 /boot=5000 /seed=20261126.
process y=distress /x=alex /m=avoid dysreg /model=6 /total=1 /boot=5000 /seed=20261126.
process y=distress /x=alex /w=support /model=1 /jn=1.
process y=distress /x=alex /w=support /model=1 /center=1 /moments=1.
```
메뉴(대화상자)로 실행해도 됨. 같은 변수·옵션만 맞추면 됨.

### 비교 기준 (제안)
| 항목 | 기대 | 판단 기준 |
|---|---|---|
| 분석 사례 수 | 같음 | 완전 일치 |
| 회귀계수·SE·t·p·R²·F | 같음 | PROCESS 출력 자릿수(소수 4자리)에서 일치 |
| 간접효과 점추정 | 같음 | 소수 4자리 일치 |
| 조건부 효과 | 같음 | W 값이 같다면 소수 4자리 일치 |
| 조절변인 백분위 값 | 확인 필요 | 백분위 계산 정의가 다르면 W 값이 달라질 수 있음 → 차이 나면 정의를 맞춤 |
| 부트스트랩 신뢰구간 | 근사 | 난수 생성기가 달라 정확히 같을 수 없음. 우리 도구를 시드만 바꿔 여러 번 돌린 결과 범위 안에 PROCESS 값이 들어오는지 확인 |
| Johnson-Neyman 경계 | 같음 | 소수 3자리 일치 |

### 기록 방법
SPSS 출력 화면 캡처 + 우리 도구 결과 저장(보고서 HTML·설정 JSON) → 항목별 표로 정리 → 발표자료에 사용.

## 5. 아직 하지 않은 것

- SPSS PROCESS 비교
- 실제 연구 자료(또는 공개 예제 자료)로 시험
- 사용자(팀원·초보 연구자) 사용성 점검
- (완료) 웹 배포: GitHub Pages `https://kte09231004-hash.github.io/model-writer-2026/`

- 신뢰구간 한계값이 0에 가까워 시드에 따라 결론이 바뀔 수 있는 경우를 알려 주는 기능
- Johnson-Neyman '계산 불가' 상태: 코드에는 있으나, 이 상태를 일으키는 실제 데이터로는 시험하지 못함
- 이전 결과를 따로 저장하는 기능은 두지 않음(재분석 필요·실패 상태에서는 저장 차단)
